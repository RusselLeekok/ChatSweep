# ChatTidy

ChatTidy 是一个本地运行的 Manifest V3 浏览器扩展，用来在多个 AI 聊天网站中批量选择并删除聊天记录。

当前 MVP 支持：

- ChatGPT
- Grok
- Gemini
- DeepSeek
- 豆包

## 设计原则

- 只读取当前页面已渲染的侧栏聊天，不读取聊天正文。
- 不读取或保存网站登录令牌。
- 不连接开发者服务器，不包含统计和追踪。
- 删除前显示选中数量和标题预览。
- 所有站点都通过页面可见的原生菜单和确认窗口完成删除。
- ChatGPT 点击原生确认后只等待确认按钮关闭，立即处理下一条，不等待侧栏记录消失。
- 站点结构不匹配时进入安全模式，不猜测删除按钮。

## 本地开发

```bash
npm install
npm run check
```

在 Chrome 或 Edge 中打开扩展管理页，启用开发者模式，选择“加载已解压的扩展程序”，然后选择 `dist` 目录。

## 使用

1. 打开受支持的 AI 网站并登录。
2. 点击页面右下角的 ChatTidy，或点击浏览器工具栏中的扩展图标。
3. 点击“选择聊天”。
4. 勾选侧栏中当前可见的聊天。
5. 点击“删除”，核对标题并确认。

MVP 暂不自动滚动加载全部历史记录。虚拟列表中的未渲染聊天不会被选择，以避免误删。

## 项目状态

`0.3.5` 根据登录后的真实 Grok DOM 修复菜单触发：侧栏的“备选方案”按钮隐藏在聊天链接内部，Grok 使用 Radix 的 `pointerdown` 打开菜单。适配器现在只向该按钮发送鼠标主键 `pointerdown`，并禁止回退为会冒泡打开对话的 `click()`；Grok 点击删除后直接执行，不等待确认弹窗。各 AI 网站会频繁更新 DOM，适配器仍需持续真实账号回归。

调研与方案对比见 [docs/research.md](docs/research.md)。
